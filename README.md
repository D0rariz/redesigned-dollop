#  FinanceBot — Telegram-бот для управления личными финансами

## Описание проекта

FinanceBot — это персональный финансовый помощник в Telegram.
Бот позволяет вести учёт доходов и расходов, отслеживать категории трат,
устанавливать лимиты, копить на цели и следить за курсом валют — всё
прямо в мессенджере.

## Используемые технологии

- Python 3.11+
- pyTelegramBotAPI (telebot) — Telegram Bot API
- requests — HTTP-запросы к внешнему API курсов валют
- json — хранение данных пользователей
- re — регулярные выражения для парсинга сообщений
- datetime — работа с датами и фильтрация по месяцам
- abc — абстрактные классы (ABC, abstractmethod)

## Установка

1. Клонируй репозиторий:
   git clone https://github.com/username/finance-bot.git
   cd finance-bot

2. Установи зависимости:
   pip install -r requirements.txt

3. Вставь токен бота в Config.TOKEN (получить у @BotFather в Telegram)

## Запуск

   python bot.py

После запуска в консоли появится: "Бот запущен..."

## Основные функции

| Команда / Кнопка    | Описание                                  |
|---------------------|-------------------------------------------|
| /start              | Приветствие, сохранение имени             |
| 💰 Баланс           | Текущий баланс в тг и USD                 |
| ➕ Доход            | Добавление дохода с источником            |
| ➖ Расход           | Добавление расхода с категорией           |
| 📊 Статистика       | Расходы по категориям за текущий месяц    |
| 📋 История          | Последние 10 операций                     |
| 🎯 Цели             | Прогресс накоплений                       |
| /add_goal           | Создать новую цель накопления             |
| /save_to_goal       | Пополнить цель со счёта                   |
| ⚙️ Лимиты          | Просмотр лимитов по категориям            |
| /set_limit          | Установить лимит для категории            |
| 💱 Курс валют       | USD/KZT и EUR/KZT в реальном времени      |

## Быстрый ввод расходов (Natural Language)

Бот понимает свободный текст:
- расход 1500 донер
- потратил 2000 на такси
- купил кофе за 800

## Примеры работы

1. Пользователь пишет "расход 3500 суши"
2. Бот определяет сумму и описание через regex
3. Если категория неизвестна — спрашивает один раз
4. Запоминает связку "суши → еда" в smart_map
5. В следующий раз категория определяется автоматически
